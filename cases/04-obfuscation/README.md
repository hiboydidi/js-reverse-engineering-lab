# 案例 04：简单字符串混淆还原

## 目标

把变量名和字符串索引被替换的教学代码恢复成可读逻辑。

## 方法

1. 识别字符串数组。
2. 找到索引偏移。
3. 制作索引到字符串的对照表。
4. 替换所有索引调用。
5. 给临时变量重新命名。
6. 根据输入输出推导每个分支。
7. 重写清晰版本，并与原函数做差分测试。

## 观察点

- _0xwords 保存了哪些字符串？
- _0xword 如何把整数索引转换为数组下标？
- _0xamount、_0xcut 分别代表什么？
- 对象属性名是否也来自字符串表？

## 不要做的事

不要因为代码看起来混乱就直接猜算法。先记录映射，再根据执行结果验证。
