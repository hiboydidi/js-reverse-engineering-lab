# 案例 01：优惠券逻辑还原

## 目标

分析一个本地教学脚本，找出优惠券规则，并独立写出可读版本。

## 入口文件

- 页面：labs/03-obfuscation/index.html
- 调用入口：labs/03-obfuscation/main.js
- 教学样本：labs/03-obfuscation/sample-obfuscated.js

## 操作步骤

1. 启动项目并打开 03 · 混淆识别。
2. 在 Sources 中打开 sample-obfuscated.js。
3. 先找字符串数组，再找索引函数。
4. 将索引表达式逐一替换成对应字符串。
5. 找到两个优惠码分支，记录各自的计算方式。
6. 在 Console 或页面中测试 200、1000、10 三种小计。
7. 自己写一份不带混淆变量的实现。

## 必须回答

- 索引 0x30、0x31 分别对应什么字符串？
- LAB10 的折扣是否有上限？
- FIXED20 在小计低于 20 时会发生什么？
- 未知优惠码如何处理？
- 为什么金额计算要统一保留两位小数？

## 验收

- 能解释每个分支。
- 能写出等价的清晰函数。
- 至少覆盖正常、上限、低于固定折扣、无效优惠码四类测试。

答案提示位于 solutions/01-coupon.md。建议完成后再查看。
