# JS 逆向常用术语

| 术语            | 含义                                   |
| --------------- | -------------------------------------- |
| Entry Point     | 程序或功能的入口                       |
| Call Stack      | 当前函数调用链                         |
| Scope           | 当前可访问的变量作用域                 |
| Closure         | 函数与其词法环境的组合                 |
| Prototype Chain | 对象属性查找的原型链                   |
| Event Loop      | 管理同步任务、微任务和宏任务的事件循环 |
| Fetch           | 浏览器发起 HTTP 请求的 Promise API     |
| XHR             | XMLHttpRequest，较早的浏览器请求 API   |
| Initiator       | Network 面板中显示请求由谁触发         |
| Bundle          | 打包工具生成的代码产物                 |
| Source Map      | 将生成代码映射回源代码的文件           |
| Minification    | 删除空白、缩短标识符等压缩操作         |
| Obfuscation     | 增加阅读难度的代码混淆                 |
| Hook            | 在函数或 API 边界观察调用参数与返回值  |
| Digest          | 单向摘要计算，例如 SHA-256             |
| HMAC            | 基于哈希函数和密钥的消息认证码         |
| WebSocket       | 浏览器与服务器之间的双向通信协议       |
| HAR             | HTTP Archive，网络请求归档格式         |
